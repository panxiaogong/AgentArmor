# MASW Figure Set

Publication-ready SVG diagrams generated for the current Type 5 report.

| File | Purpose |
|---|---|
| `fig1_masw_overall_architecture.svg` | Overall MASW defense architecture |
| `fig2_attack_chain_vs_defense.svg` | Vulnerable attack chain vs MASW protected path |
| `fig3_d3_hybrid_detector.svg` | D3 hybrid risk detector exploded view |
| `fig4_d4_provenance_gate.svg` | D4 provenance-aware trust promotion gate |
| `fig5_evaluation_protocol.svg` | Evaluation protocol and key metrics |
| `generate_publication_figures.py` | Deterministic generator for the SVG figure set |

Style: flat 2D vector, white background, Morandi pastel palette, English labels.

The current version uses a strict 1600x900 canvas, aligned flat tensor strips,
uniform rounded modules, and grid-based coordinates to avoid skewed manual
placement.
