# AgentArmor Demo Web

这是 AgentArmor 的本地真实模块演示页。浏览器负责展示，Python 服务会为每次运行创建新的证据目录，并实际调用项目防御模块。

## 启动

在本目录运行：

```powershell
python demo_server.py
```

然后打开 `http://127.0.0.1:4173`。

如果本机已有旧版演示服务占用 4173，可临时换端口：

```powershell
$env:AGENTARMOR_DEMO_PORT=4183
python demo_server.py
```

## 当前范围

- 无防护与 AgentArmor 双轨对比
- 逐步执行、自动播放和重置
- 端到端污染、知识库后门、多 Agent、级联撤销和完整性场景
- 记忆数据库、审计日志和实验指标面板

页面不使用模拟结果兜底。点击“执行下一步”或“自动播放”后，会请求 `/api/run`，只有后端返回 `real_execution=true` 才展示结果；模块异常会直接显示为运行失败。

每次运行的 SQLite、工具沙箱与完整性证据保存在 `runtime/REAL-*`，该目录已被 Git 忽略。

## 批量测试

页面右上角切换到“批量测试”后，可以单独运行任一数据集，也可以选择“完整报告复现”一次执行全部本地测试入口：

- 端到端闭环：38 条样本（30 攻击、8 良性）
- 类型一 AutoWrite：120 条样本
- 类型二 MINJA：120 条样本及检索专项
- 类型三 Reflection：40 条写入样本及 2 组检索场景
- 类型四主集：164 条样本 × 5 种本地方法
- 类型四困难集：118 条样本 × 5 种本地方法
- 类型五困难集：136 条样本 × 5 种防御配置
- D7 级联撤销：20 条样本

完整模式共执行 758 组测试（其中撤销 20 组复用 Type 5 攻击内容），产生 2440 条可查看结果记录和 2780 次实际模块执行。批量结果会同时展示本次实测、报告只读参照和差异状态。表格支持按模块、配置、标签、错误类型、编号和攻击类别筛选；点击任意一行可以查看输入、中文释义、攻击影响、来源、原始判决、实际模块和证据目录。
